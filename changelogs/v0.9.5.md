# Changelog — v0.9.5

> Gerado em: 2026-06-19
> Commits: 6153a89 (v0.9.4) → ce834df (v0.9.5)

## Geral
- Novo visualizador de logs integrado ao app — acessível em Configurações > Diagnóstico, com filtro por nível (D/I/W/E), compartilhamento e limpeza
- Relatórios de crash automáticos via Firebase Crashlytics — erros e exceções são enviados automaticamente para diagnóstico remoto
- Rastreamento de navegação entre telas via Firebase Analytics
- Melhor tratamento de erros de API — mensagens de erro mais claras e consistentes em todo o app
- Logs de diagnóstico adicionados em pontos críticos (autenticação, refresh de token, downloads, sincronização) para facilitar depuração
